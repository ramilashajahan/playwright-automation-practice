# Playwright TypeScript Automation Practice

A clean practice repository demonstrating the implementation of standard end-to-end UI automation testing scripts using Playwright and TypeScript.

## 📂 Project Structure
* **pages/** - Follows the Page Object Model (POM) design pattern to separate UI elements and interactions from actual test logic.
* **tests/** - Contains modular, functional test scripts targeting web elements.
* **playwright.config.ts** - Global configurations tracking execution timeouts, browser contexts, and test reports.

## 🛠️ Tech Stack
* **Language:** TypeScript
* **Test Runner:** Playwright Test
